# Pedido Irrecusável

Este é um projeto interativo e divertido feito com **HTML**, **CSS** e **JavaScript**. A ideia é criar uma página que simula um "pedido irrecusável", com uma interface criativa e animações atraentes.

## 🖼️ Demonstração

A página exibe uma mensagem simpática: "Vamos sair hoje gatinha?" com dois botões - **Sim** e **Não**. O botão "Não" tem um comportamento especial: ele se move para lugares aleatórios quando o usuário tenta clicar, tornando impossível rejeitar o convite! Além disso, há animações de estrelas fixas e cadentes no fundo, criando um efeito visual encantador.

---

## 📁 Estrutura do Projeto

O projeto é composto pelos seguintes arquivos:

- **`index.html`**: Estrutura da página com a mensagem e os botões interativos.
- **`styles.css`**: Arquivo de estilos responsável pelo design, incluindo as animações de estrelas e o layout dos botões.
- **`script.js`**: Código JavaScript para funcionalidade interativa, como o movimento do botão "Não" e a criação das estrelas cadentes.
